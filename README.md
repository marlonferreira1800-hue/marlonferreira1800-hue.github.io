# 🌐 Marlon Ferreira - Personal Website & Portfolio (GitHub Pages)

Site minimalista e ultra-rápido baseado no padrão clássico de pesquisadores e engenheiros de IA de Berkeley/Stanford (inspirado no template de [Ryan Wang](https://ryanyxw.github.io/) e [Nelson Liu](https://nelsonliu.me/)).

## 📁 Estrutura de Arquivos

```text
portfolio-github-page/
├── index.html        # Página principal com suas informações, projetos e biografia
├── css/
│   └── style.css     # Estilos serifados elegantes (EB Garamond, Palatino) e responsivos
├── img/
│   ├── profile.jpg   # Sua foto real de perfil (basta colocar a foto aqui com esse nome)
│   └── profile.svg   # Avatar placeholder padrão caso ainda não tenha adicionado a foto
└── files/            # Coloque aqui seu currículo ou artigos (ex: curriculo.pdf)
```

## 🚀 Como Colocar no Ar no seu GitHub (Grátis via GitHub Pages)

1. No seu GitHub, crie um novo repositório chamado exatamente:
   `SEU_USUARIO.github.io` (exemplo: `marlonferreira.github.io`)
   *Defina-o como **Public**.*

2. Clone ou inicialize o git dentro desta pasta e envie para o GitHub:
   ```bash
   cd portfolio-github-page
   git init
   git add .
   git commit -m "feat: site oficial pessoal no ar"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/SEU_USUARIO.github.io.git
   git push -u origin main
   ```

3. Em 30 segundos, o seu site estará disponível mundialmente no endereço:
   👉 **`https://SEU_USUARIO.github.io`**
